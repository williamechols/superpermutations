# Superpermutations

These constructions were developed in an interactive Codex session using OpenAI’s GPT-5.6-Sol at xhigh reasoning. I supplied the direction and evaluated the results; the model developed most of the constructive method. These findings were inspired by Uku Raudvere's recent post to the Superpermutators group ([n=8 superpermutation of length 46204](https://groups.google.com/g/superpermutators/c/TBZsctlczM4)).
